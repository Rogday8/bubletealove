# Bubble Tea Love

Промо-сайт вымышленной чайной с жемчужным чаем. Концепт для портфолио, собран по видео-референсу
`../основной референс.mp4` (кейс «kumo» — стакан по центру, веер карточек вкусов вокруг, крупная
надпись за стаканом) и по палитре из `../градиент цветов.jpg`.

## Стек

| Что | Версия |
| --- | --- |
| Vite | 8 |
| React | 19 |
| TypeScript | 6 |
| Tailwind CSS | 4 (плагин `@tailwindcss/vite`, без `tailwind.config`) |
| Motion (ex-Framer Motion) | 13 |
| Lenis | 1.3 — инерционный скролл |

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173 — разработка
npm run build    # собирает dist/
npm run preview  # посмотреть собранное на локальном сервере
```

### Один файл, который можно переслать

`npm run build` собирает **`bubble-tea-love.html`** в корне проекта (он же `dist/index.html`) —
около 1,1 МБ, внутри вообще всё: React, стили, векторная графика и все фотографии в виде
`data:`-ссылок. Никаких соседних папок не нужно: файл можно кинуть в телеграм, на флешку или
на другой компьютер и открыть двойным кликом.

Единственное, что тянется из сети, — шрифты Google Fonts. Без интернета заголовки нарисуются
системным шрифтом, всё остальное работает офлайн.

## Что на странице

Заставка (полторы секунды, пропускается кликом) → герой со стаканом → бегущая строка → счётчики →
двенадцать вкусов → конструктор стакана → ритуал заваривания → палитра заведения →
«Атмосфера» с фотосеткой и просмотром по клику → отзывы → вопросы → футер.

### Корзина

`src/state/cart.tsx` + `src/components/CartDrawer.tsx`. Добавить стакан можно тремя способами:
кнопка с ценой на карточке вкуса, «Добавить в корзину» в конструкторе (уходит вся сборка —
основа, топпинг, размер, сахар, лёд) и кнопка в футере. Одинаковые позиции складываются,
количество меняется прямо в панели, содержимое переживает перезагрузку (localStorage, обёрнут
в try/catch — в приватном режиме просто не сохраняется). Счётчик в шапке подпрыгивает при каждом
добавлении.

## Как устроен герой

Сцена собрана слоями — ровно так, как просили: фон отдельно, напиток отдельно.

| z-index | Слой |
| --- | --- |
| 0 | фон: радиальный градиент вкуса + размытое фото + летающие пузыри |
| 5 | `Mound` — горка сахарной пудры, на которой стоит стакан |
| 10 | крупная надпись «Выбери свой вкус» (стакан её перекрывает) |
| 15 | название вкуса курсивом — уходит за стакан |
| 20 | `FlavorArc` — веер карточек вкусов |
| 30 | `BobaCup` — сам стакан, «вырезанный» слой поверх всего |
| 40 | интерфейс: состав, ккал, подпись вкуса, точки-переключатели |

Все слои двигаются от курсора с разной скоростью (параллакс на `useMotionValue` + пружина).

### Стакан

`src/components/BobaCup.tsx` — это не картинка, а SVG-иллюстрация: стекло, крышка, трубочка, лёд,
молочная шапка, сливочный развод, тапиока и поднимающиеся пузырьки. Напиток залит цветами из
CSS-переменных `--f-top`, `--f-bottom`, `--f-foam`, `--f-pearl`, поэтому при смене вкуса он
**перекрашивается с анимацией** (`transition: fill 900ms`), а не подменяется другой картинкой.
При каждом наливе жидкость пружинит вверх и по стакану расходится круг-всплеск.

### Смена вкуса

`src/state/flavor.tsx`:

- лента едет сама каждые **6 секунд**;
- вкус меняется **только по клику или свайпу** — наведение курсора ничего не наливает;
- ленту можно **тянуть** мышкой или пальцем вдоль дуги; резкий свайп добрасывает на вкус дальше;
- короткое нажатие по карточке = выбор этого вкуса, долгое с движением = перелистывание
  (порог 6 px; из-за захвата указателя клик ловится вручную в `onPointerUp`);
- видны только четыре ближние карточки — следующая пара гаснет до того, как сползёт на фон;
- как только её тронули, автопрокрутка встаёт и возвращается через **2,5 секунды** тишины;
- позиция ленты — дробное число (`pos`), цвета напитка, фона и свечения считаются как смесь
  соседних вкусов на каждом кадре, поэтому во время перетаскивания стакан **перетекает**
  из вкуса во вкус, а не переключается рывком;
- в покое посередине дуги оставлен просвет — за стаканом карточка не прячется;
- работают стрелки `←` / `→` на клавиатуре;
- пока курсор на карточке, автосмена стоит.

Двенадцать вкусов описаны в `src/data/flavors.ts` — добавить новый значит дописать объект:
название, состав, цена, ккал, сладость, иконка и шесть цветов. Всё остальное — веер, карточки,
фон сцены, футер — подхватится само.

### Конструктор

`src/components/Constructor.tsx` — отдельный мини-стакан, который собирается из выбора: основа,
топпинг, размер, сахар, лёд. Цена пересчитывается на лету, кубики льда появляются и исчезают
по пружине, цвет напитка и жемчуга анимируется.

## Логотип

`src/components/Logo.tsx` — значок (`LogoMark`) и строчный вариант. В шапке и футере значок
подкрашивается под выбранный вкус (`flavorAware`). Готовые файлы в `public/`:

- `logo.svg` — значок + название в строку;
- `logo-mark.svg` — только значок (он же `favicon.svg`);
- `logo-mark-1024.png`, `-512`, `-256` — растр для аватарок и соцсетей (прозрачных углов нет,
  это скруглённая плитка).

Идея простая: белый стакан с трубочкой, жемчуг на дне и сердце вместо пара.

## Палитра

Снята пипеткой с `градиент цветов.jpg` (`src/index.css`, блок `@theme`):

`#fbdedb` кремовый · `#f7cbcc` блаш · `#eea3a8` роза · `#e17a62` коралл · `#c46251` терракота ·
`#f19d5f` янтарь · `#7c423b` какао · `#2a1114` ночь.

Каждый вкус дополнительно тянет за собой свой фон сцены и свечение.

## Картинки

Все изображения лежат в `src/assets/` и импортируются из кода — поэтому при сборке уезжают
внутрь одного HTML-файла:

- `src/assets/media/` — фотографии заказчика: `sakura-cups.webp` (из `градиент цветов.jpg`),
  `blue-lagoon.webp` (из `отражение св.png`) и размытая крошка для фона героя;
- `src/assets/photos/` — двенадцать снимков со стоков под блок «Атмосфера», по две версии:
  4:5 для плитки и 16:9 для полноэкранного просмотра. Все в WebP — вместе весят 480 КБ.
  Источники и лицензии — в `CREDITS.md`.

Фрукты на карточках — векторные (`src/components/FruitIcon.tsx`), не фото: масштабируются без
потерь и весят ноль. Если захочется фото-рендеры из Higgsfield — в `HIGGSFIELD.md` лежат готовые
промпты и инструкция, куда класть файлы.

## Доступность и производительность

- `prefers-reduced-motion` выключает анимации и инерционный скролл;
- у карточек есть фокус-обводка и `aria-label`, вкусы листаются с клавиатуры;
- фотографии грузятся лениво, анимации — только `transform` / `opacity` / `fill`.
